# Official Materials Library

This directory contains **legal/authoritative material anchors**, not pirated copies of commercial books.

## Knowledge sources
- NCERT official textbooks
- IGNOU eGyanKosh
- User-supplied legitimate copies of selected commercial/reference books, mapped through the Project knowledge library

## Source of Truth
- Union Budget
- Economic Survey
- RBI
- MoSPI
- NITI Aayog
- Parliament
- India Code
- Other registered primary institutions

## Syllabus
The operational syllabus taxonomy is in `taxonomy/master_index.json`. Its official provenance is recorded in `materials/official_materials.json`.

The CSE 2027 notification/syllabus will supersede the historical notification anchor when UPSC publishes it.

## PYQs
Official UPSC PYQ provenance for CSE 2016–2026 is recorded in `pyqs/paper_index.json`.

Question-level text should be processed only from official UPSC PDFs or legitimately supplied copies; generated questions must never be labelled as PYQs.
