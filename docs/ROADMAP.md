# UPSC-RAG Roadmap

## Phase 1 — Foundation

- repository structure
- source hierarchy
- official syllabus taxonomy
- source registry
- record schemas
- PYQ registry
- current-affairs registry
- relationship model
- validation

## Phase 2 — High-value corpus

1. Verify official syllabus/version.
2. Register core Source of Knowledge books as they enter the ChatGPT Project.
3. Build PYQ metadata and question records from official UPSC papers.
4. Add high-value source-of-truth records for major GS/Optional domains.
5. Start current-affairs records from May 2026.

## Phase 3 — Retrieval

Add lightweight local/full-text retrieval only where it materially improves the workflow.

## Phase 4 — Evidence-based upgrade

Only if structured retrieval demonstrates repeated failures:
- introduce embeddings
- evaluate a local vector index
- benchmark retrieval quality
- retain a zero-cost path

## Never

- build a crawler just because crawling is possible
- ingest every news article
- copy whole copyrighted books into GitHub
- add paid infrastructure without demonstrated need
- confuse repository completeness with exam readiness
