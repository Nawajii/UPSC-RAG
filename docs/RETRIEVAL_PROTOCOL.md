# Retrieval Protocol

## Request classification

### Factual
Return:
1. answer
2. strongest authoritative source
3. date/version if relevant

### Verification
Return:
1. claim
2. verification status
3. supporting authority
4. conflict/uncertainty if any

### Topic map
Return:
1. syllabus placement
2. source of knowledge
3. source of truth
4. PYQs
5. current affairs
6. UPSC relevance
7. gaps

### Current-affairs request
Prioritise developments from May 2026 onward and connect each retained item to static syllabus topics.

## Source selection

1. Prefer Tier 1 for truth.
2. Use Tier 2 for learning.
3. Use Tier 3 for analytical depth.
4. Use Tier 4 primarily for discovery/context.
5. For important claims found in Tier 4, trace to Tier 1 where reasonably possible.

## Conflict protocol

If sources disagree:
- preserve both claims
- preserve dates
- preserve source authority
- identify the authoritative/current position where determinable
- do not erase the historical claim

## Output discipline

Do not dump the corpus.

Return only what is necessary for the user's request, with enough provenance to verify important claims.
