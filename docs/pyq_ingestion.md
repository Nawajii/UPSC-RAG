# PYQ ingestion policy

## Verified provenance
Official UPSC paper index:
https://www.upsc.gov.in/examinations/previous-question-papers

Official archive:
https://www.upsc.gov.in/examinations/previous-question-papers/archives

## Question-level records
The repository stores structured metadata and official provenance. It does not redistribute full question papers copied from the public web.

When official PDFs are supplied for lawful processing, each question should be normalized into:

- id
- year
- stage
- paper
- question_number
- question
- marks
- syllabus_id
- subtopic
- concept_tested
- question_type
- analytical_difficulty
- source_of_knowledge
- source_of_truth
- recurring_theme
- current_affairs_connection
- official_provenance
- status

Analytical fields are our classifications, not UPSC's official classifications.

## 2026 baseline
UPSC's current official previous-paper index lists CSE 2026 Prelims GS-I/GS-II and CSE 2026 Mains GS-I through GS-IV, Essay and Economics Papers I-II.

The same official index and archive should be used to expand the paper index backward year-by-year.
