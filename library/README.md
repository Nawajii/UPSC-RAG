# UPSC CSE 2027 Knowledge Library

This directory is the corpus layer of UPSC-RAG.

## Principle

- Open/official material is indexed here and can be ingested where technically and legally appropriate.
- Commercial copyrighted books are not copied into this public repository; legitimate copies should be uploaded to the ChatGPT Project/library.
- Source of Truth remains distinct from Source of Knowledge.
- A URL/index entry is not evidence; the exact document/page must be verified before a claim is treated as authoritative.

## Ready to ingest from official/open sources

- NCERT textbooks
- UPSC official question papers
- Union Budget documents
- Economic Survey
- RBI reports/statistics/monetary-policy material
- NITI Aayog reports
- MoSPI statistics
- Parliament/Sansad material
- India Code legislation
- IGNOU eGyanKosh selected material
- Other primary government/regulator/international documents selected by syllabus relevance

## Teaching rule

Subject threads retrieve from this library first, verify important/current claims against the Source-of-Truth layer, then connect the topic to PYQs and current affairs.
