# Question-Level PYQ Layer

Question-level records are created only from the actual official UPSC papers or official PDFs lawfully supplied for processing.

Do not reconstruct PYQs from memory or coaching compilations and label them as official.

Each record follows schema/pyq_record.schema.json and must retain official provenance.

Recommended ingestion order:
2026 Prelims GS-I → 2026 CSAT → 2026 Mains GS-I → GS-II → GS-III → GS-IV → Essay → Economics I → Economics II, then 2025, 2024, 2023 and older years.
