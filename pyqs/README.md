# PYQ Database

Actual UPSC PYQs only.

## Required metadata

Each PYQ record should contain:

- id
- year
- examination
- stage
- paper
- question
- marks, where applicable
- syllabus_ids
- subtopic
- concept_tested
- question_type
- difficulty_assessment
- source_of_knowledge_ids
- source_of_truth_ids
- recurring_theme_ids
- current_affair_ids
- official_source_url
- status

Analytical fields such as difficulty and concept tested are **our metadata**, not official UPSC classifications.

Generated practice questions belong elsewhere and must never be labelled as PYQs.

## Provenance rule

A question becomes VERIFIED only when its official UPSC provenance is established.

The official UPSC previous-question-paper repository is the primary PYQ source:
https://www.upsc.gov.in/examinations/previous-question-papers
